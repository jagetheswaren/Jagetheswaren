## Featured Work

### IntelliReview AI
**AI-powered code review assistant for actionable software-quality feedback.**

**Problem:** Reviewing code for security, quality, complexity, and performance issues can be slow and inconsistent.

**Solution:** A full-stack platform that combines static analysis, machine-learning severity prediction, NLP explanations, local-LLM summaries, and GitHub pull-request workflows.

**Tech stack:** Python, Flask, React, Tailwind CSS, MongoDB Atlas, Scikit-learn, Hugging Face Transformers, Ollama, Bandit, Pylint, Radon, GitHub REST API, JWT, bcrypt, Docker, Vercel, Render.

**Key features:** Security and AST analysis; code-smell, complexity, and performance checks; CodeBERT explanations; GitHub repository and PR analysis; report exports; responsive dashboard.

**Focus:** AI/ML, NLP, static analysis, developer tools, full-stack engineering.

[Repository](https://github.com/jagetheswaren/AI-Code-Review-Assistant) | [Live app](https://frontend-delta-eight-92.vercel.app) | [API](https://ai-code-review-api.onrender.com)

### EventAI
**AI-assisted event planning and management for organizing events from idea to booking.**

**Problem:** Event planning combines budgeting, vendors, bookings, visual planning, and coordination across disconnected workflows.

**Solution:** A mobile-first event platform concept with AI suggestions, budget estimation, vendor management, booking flows, and AI-based room transformation.

**Tech stack:** React Native, Expo, TypeScript, Supabase, AI APIs, GitHub Actions.

**Key features:** AI event planning; vendor marketplace concepts; booking and event-management workflows; administrative capabilities; generative image and room-transformation ideas.

**Focus:** Generative AI, mobile development, product workflows, full-stack applications.

[Live web build](https://jagetheswaren.github.io/Online-Event-AI/)

### AI BloodLink
**An intelligent emergency blood-network concept connecting patients, hospitals, blood banks, and donors.**

**Problem:** Emergency blood requests require timely communication and coordination between multiple participants.

**Solution:** A web/mobile/admin architecture aimed at organizing donor, hospital, and blood-bank workflows with real-time communication and AI-assisted matching concepts.

**Tech stack:** TypeScript, Vue, Vite, Tailwind CSS, backend and database systems.

**Key features:** Patient, hospital, blood-bank, and donor workflows; administrative interfaces; real-time coordination concepts; AI-powered assistance and matching exploration.

**Focus:** Healthcare technology, real-time systems, web applications, backend architecture.

### AgriSentinel AI / AgriNova
**An intelligent autonomous agricultural rover concept for data-informed farm operations.**

**Problem:** Farmers need timely, localized insight into soil condition, crop stress, and field risks.

**Solution:** A modular rover concept combining sensing, AI, computer vision, edge AI, robotics, and farmer notifications to support precision agriculture.

**Tech stack:** AI, computer vision, edge AI, robotics, IoT sensors.

**Key features:** Soil monitoring concepts for NPK, pH, EC, and moisture; crop-stress detection; precision fertilizer application; wildlife detection; autonomous navigation; farmer notifications.

**Focus:** AI, computer vision, robotics, IoT, edge AI.
